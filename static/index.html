Settings

Email account

Lets the Mail agent read (IMAP) and send (SMTP) your email. For Gmail, turn on 2-step verification and create an app password; your normal password won't work. The password is stored only on this computer, in data/secrets.json.

Calendars

Lets the Planner, or any agent with “Read your calendars”, see your schedule. Read-only. Paste each calendar's private iCal link. Google: calendar settings → your calendar → “Secret address in iCal format”. iCloud: share the calendar publicly and copy the webcal:// link. Outlook: Settings → Calendar → Shared calendars → Publish → ICS link. A path to an .ics file also works. Links stay on this computer.
